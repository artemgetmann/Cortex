# Research Docs

AGI research artifacts live here.

## Render `agi-ideas.jsx` in Safari

```bash
cd docs/research/viewer
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

Then open:

`http://127.0.0.1:4173`

The viewer imports `docs/research/agi-ideas.jsx` directly, so edits to that file hot-reload.
